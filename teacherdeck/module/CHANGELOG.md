# 변경 기록

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.0

- 필요 앱 버전: 0.3.0. messaging 1.0 / storage 1.0 / fs 1.1이 필요합니다.
- 원작 새 메시지·제목 공란·공동 수신·반복·예약표·대량 입력·일반 자료·선택형 중식 지도를 덱 화면으로 옮겼습니다.
- Excel·CSV·표 붙여넣기·빈 엑셀 양식·저장 양식·보관·상태·업무 CSV·모듈 JSON 백업을 제공합니다.
- 동명이인·수신자 변경·원본과 개별 수정 충돌·이미 제출한 날짜/차시·불확실한 등록 결과의 재등록을 보호합니다.
- 첨부는 선택한 핸들로만 전달합니다. 연결이 첨부 등록을 검증하지 못하면 초안을 보존하고 안내합니다.
- 여섯 messaging 메서드로 검토·호스트 최종 확인·진행·중지를 연결하고 청크 저장은 실패 시 이전 값을 유지합니다.
- Google 직접 연결은 비활성화되어 있습니다. 원작 전체 DB/프로필·쿨메신저 전체 기록을 백업·조회한다고 표시하지 않습니다.
- CoolReserve contributors의 MIT 고지와 저자 표기를 유지했습니다.
