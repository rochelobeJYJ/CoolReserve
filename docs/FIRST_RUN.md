# 처음 사용 안내

처음에는 **다운로드 → 압축 해제 → Python 설치 → INSTALL → 쿨메신저 준비 → START → 계정 불러오기 → 본인 시험** 순서로 진행합니다. 다음부터는 쿨메신저를 준비하고 START만 실행하면 됩니다.

## 다운로드와 설치

Windows PC와 기관 계정으로 로그인할 수 있는 쿨메신저 Gentoo가 필요합니다. 설치할 때 인터넷에 연결되어 있어야 합니다. Excel 프로그램과 Google 계정은 없어도 됩니다.

1. [최신 버전 다운로드](https://github.com/rochelobeJYJ/CoolReserve/releases/latest)에서 첨부된 배포 ZIP을 받습니다. 대안은 [저장소](https://github.com/rochelobeJYJ/CoolReserve)의 **Code → Download ZIP**입니다.
2. ZIP을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**를 선택하고 쓰기 가능한 폴더에 모두 풉니다. ZIP 안에서 직접 실행하거나 `START.cmd`만 다른 곳으로 옮기지 마세요.
3. [Python 공식 Windows 배포](https://www.python.org/downloads/windows/)에서 **Python 3.14의 64비트 Windows 설치 프로그램**을 받아 설치합니다. 설치 화면에 `Add python.exe to PATH`가 있으면 선택하세요. 이미 Python 3.14 64비트가 설치되어 있으면 이 단계는 건너뜁니다.
4. 압축을 푼 폴더의 **INSTALL.cmd**를 두 번 누릅니다. 창을 닫지 말고 설치 완료 안내를 기다립니다. 패키지는 해당 폴더의 `.venv`에 설치됩니다.

설치 성공을 확인한 뒤 다음 단계로 넘어가세요. 설치 제한이나 인터넷 오류가 나오면 [문제 해결](#문제-해결)을 확인합니다. 관리자 권한 실행을 기본 해결책으로 사용하지 마세요. 기관에서 설치를 제한한다면 담당 관리자에게 확인하세요.

새 환경 설치·재실행은 **Python 3.14 64비트**에서 확인했습니다. Python 3.13 64비트도 지원 조건에 포함되지만 별도의 새 설치 시험은 하지 않았습니다.

## 쿨메신저 준비와 앱 실행

5. **쿨메신저에 로그인하고 조직도 창을 엽니다.** 조직도는 온라인 사용자만 표시하지 않도록 전체 표시로 바꿉니다. 작성 중인 메시지는 내용을 보관한 뒤 닫습니다.
6. 압축을 푼 폴더에서 **START.cmd**를 두 번 누릅니다. 브라우저에 쿨 예약실이 열리면 준비가 끝났습니다.

지원되는 Gentoo에서는 작성창을 미리 열거나 특정 위치에 창을 놓을 필요가 없습니다. 다중 모니터에서도 사용할 수 있습니다. 이후에는 쿨메신저 로그인·조직도를 확인하고 START만 실행하세요. 여러 번 실행해도 기존 서버를 재사용합니다.

## 처음 연결

7. 화면의 **조직도 계정 불러오기**를 누릅니다. 이름·소속·계정 표시를 확인하고 화면 안내에 따라 연결을 저장합니다. 계정과 지원 화면 설정은 이 PC에 저장됩니다. 계정을 읽고 연결하는 것만으로 메시지를 보내지는 않습니다.

기존 연결은 매번 다시 설정하지 않습니다. 명단이 바뀌거나 계정이 누락되면 쿨메신저의 표시 필터와 로그인 상태를 확인한 뒤 다시 불러오세요. 동명이인은 이름만 보고 고르지 말고 소속과 실제 계정을 확인합니다. 다른 PC의 개인 연결 정보는 배포하지 않습니다.

## 본인에게 한 건 시험하기

8. 먼저 본인에게 보낼 한 건으로 사용 중인 기관 환경을 확인합니다.

- 앱의 **쿨메신저 연결**에서 **본인 계정 한 번 연결** 안내가 보이면 현재 로그인한 본인의 전체 계정 표시를 선택해 연결합니다. 본인은 일반 검색 대신 **나에게 보내기**로 처리하므로 다른 계정을 대신 지정하지 마세요.
- **새 메시지**에서 본인을 선택합니다. 날짜·시간은 **현재보다 10분 이상 뒤**, 제목은 `예약 시험`, 내용은 `예약 등록 시험입니다.`처럼 시험임을 알 수 있게 입력합니다.
- **내용 확인**을 누르고 받는 사람·본문·예약시각을 다시 봅니다. **등록 가능 1건 · 수정 필요 0건**인지 확인한 뒤 등록합니다.
- 등록이 끝날 때까지 마우스·키보드를 사용하지 않습니다. **등록 요청 완료**가 나오면 정상 처리입니다. 실제 도착을 기다리지 않아도 프로그램의 다음 작업을 진행할 수 있습니다.

본인 계정이 목록에 없거나 자동 연결이 중단되면 다른 사람을 시험 대상으로 바꾸지 말고 [문제 해결](#문제-해결)을 확인하세요. 시험 예약을 취소하려면 쿨메신저에서 처리합니다. 이 앱 목록에서 숨기거나 프로그램을 종료하는 것으로 예약이 취소되지는 않습니다.

제목은 선택 사항입니다. 다만 제목 없는 입력·대조는 자동 검사로 확인했고, 이 변경 후 쿨메신저에서 제목 없이 보내기를 완료하는 실사용 시험은 하지 않았습니다. 첫 환경 확인은 위 예시처럼 제목을 넣어 진행하세요.

## 메시지 작성

**새 메시지**에서 받는 사람·날짜·시간·본문을 입력합니다. 제목은 비워도 됩니다. 여러 사람에게 같은 내용을 보낼 때는 **여러 명 선택 · 명단 붙여넣기**를 사용합니다.

수신자·내용·예약시각이 완성된 표는 **예약표 가져오기**에서 Excel·CSV를 읽거나 표를 붙여넣습니다. 제목 열은 없어도 됩니다. 열을 생략하거나 순서를 바꿨다면 열 이름까지 함께 복사하세요. Excel 앱이 없어도 파일을 읽을 수 있습니다.

일정·배정표에서 안내 문구를 만들려면 **자료로 메시지 만들기**를 사용합니다. 기본인 **일반 양식**은 날짜·수신자 열을 연결하고 `{열 이름}`을 문구에 넣어 회의·당번·공지 등에 사용합니다. 설정을 저장하면 다음 달 자료에도 다시 사용할 수 있습니다.

**중식 지도**는 선택 프리셋입니다. 선택하면 전용 양식과 차시 설정이 표시됩니다. 확정된 1·2차 담당자 배정표에서 안내 메시지를 만들며, 담당자 배정 자체를 계산하지는 않습니다. Google 시트를 연결하지 않아도 Excel·CSV·붙여넣기로 사용할 수 있습니다.

미리보기의 **등록 가능 N건 · 수정 필요 M건**을 확인하고 표시된 오류를 수정한 뒤 등록합니다. 한 번 시작하면 각 메시지를 차례로 처리하며 건마다 확인 버튼을 누를 필요는 없습니다.

## 실행 중

시작 전 쿨메신저 로그인과 열린 조직도를 확인하고, 작성 중인 내용을 보관한 뒤 다른 작성창을 닫으세요. 필요한 작성창은 프로그램이 엽니다.

등록이 끝날 때까지 마우스·키보드 입력을 멈추고 창·모니터·배율을 바꾸지 마세요. PC가 잠기거나 절전에 들어가지 않게 하세요. 완료 또는 중단 안내 뒤 다시 사용합니다. 브라우저 탭을 닫아도 등록이 자동 취소되지는 않습니다.

F8·중지는 다음 중지 확인 단계에서 반영됩니다. 접수된 예약 취소는 쿨메신저에서 처리합니다.

정상 결과는 **등록 요청 완료**입니다. **확인 기록 남기기**는 선택이며, 다음 메시지 진행 조건이 아닙니다. 보내기 전 **중단**은 원인을 수정한 뒤 다시 실행할 수 있습니다. **등록 여부 불명**이나 등록 시도 이력이 있는 건은 자동 재등록이 잠기므로 쿨메신저에서 먼저 확인하세요.

## Google 시트 연결 · 선택

직접 연결하려면 [Google 연결 안내](google-connection.html)를 따르고 본인 계정으로 읽기 권한을 승인하세요. 본인이 준비한 데스크톱 OAuth 클라이언트가 필요합니다. 인증 파일과 개인 시트 주소를 공개 저장소나 오류 제보에 올리지 마세요.

## 문제 해결

| 상황 | 확인할 것 |
| --- | --- |
| INSTALL에서 Python을 찾지 못함 | Python 3.14 64비트를 설치하고 INSTALL을 다시 실행. 아래 경로 직접 지정 방법도 사용 가능 |
| 32비트 또는 지원하지 않는 Python이라는 안내 | 64비트 Python 3.14 설치. 쿨메신저 설치와 별도로 Python의 버전을 확인 |
| 패키지 다운로드·설치 실패 | 인터넷과 기관의 설치·보안 정책 확인 후 INSTALL 재실행. 실패 상태에서 START로 넘어가지 않기 |
| START가 환경이 없거나 불완전하다고 안내 | 압축을 모두 풀었는지 확인하고 같은 폴더의 INSTALL부터 실행 |
| 압축 해제·파일 실행이 차단됨 | 파일 출처와 오류 문구 확인 후 기관 관리자에게 문의. 보안 기능을 일괄 해제하지 않기 |
| 예전 주소가 열리지 않음 | START.cmd로 현재 주소 열기 |
| 계정이 일부만 나옴 | 조직도 전체 표시와 사용자 권한 확인 후 다시 읽기 |
| 본인을 수신자 검색에서 찾지 못함 | 쿨메신저 연결에서 본인 계정을 한 번 연결. 본인에게는 나에게 보내기 방식을 사용 |
| 등록 버튼 비활성 | 수정 필요 항목, 모의 모드, 계정 연결, 진행 중 작업 확인 |
| 제목 없는 표를 잘못 읽음 | 열 이름을 함께 복사. 열을 생략한 표는 위치를 추측하지 않음 |
| 다른 창에 가려져 중단 | 작성 중인 내용을 보관하고 불필요한 작성창 정리 |
| 등록 요청 완료 | 정상 결과. 확인 기록은 필요할 때만 남기기 |
| 중단 | 보내기 전 오류 원인을 수정한 뒤 미등록 건만 다시 실행 |
| 등록 여부 불명 | 자동 재등록 잠금. 쿨메신저에서 해당 건을 먼저 확인 |
| 지난 목록이 남음 | 지난 메시지 정리·보관함 이용 |

Python 경로를 직접 지정해야 한다면 압축을 푼 폴더에서 PowerShell을 열고 아래 경로를 본인의 Python 설치 경로로 바꿔 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\install.ps1 -PythonPath "C:\Python314\python.exe"
```

기존 `.venv`가 손상됐다면 앱 메뉴의 **프로그램 종료**로 정상 종료하고 `.venv` 폴더 이름을 바꾼 뒤 INSTALL을 다시 실행할 수 있습니다. **업무 데이터가 저장되는 `%LOCALAPPDATA%\CoolReserve`는 삭제하지 마세요.** 브라우저만 닫는 것으로 서버가 종료되지는 않습니다.

해결되지 않으면 [GitHub Issues에 제보](https://github.com/rochelobeJYJ/CoolReserve/issues)해 주세요. 오류 문구, 재현 순서, Windows·Python·쿨메신저 버전을 적고 예시는 가상 이름과 가상 본문으로 바꿉니다. **진단 정보**를 내보냈더라도 내용을 먼저 확인하세요. 실제 명단·메시지·기관 화면·인증 파일은 첨부하지 마세요. [개인정보 안내](PRIVACY.md)에서 공유 범위를 확인할 수 있습니다.
