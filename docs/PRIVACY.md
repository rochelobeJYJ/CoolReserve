# 개인정보와 데이터

## 로컬 저장

기본 위치는 `%LOCALAPPDATA%\CoolReserve`입니다. 이름·계정 연결, 메시지, 예약시각, 결과, 원본 스냅샷, 저장한 업무 양식이 포함될 수 있습니다. Google을 연결하면 인증 관련 파일도 저장합니다. 이 폴더를 공개하거나 버그 보고에 첨부하지 마세요.

**예약표 가져오기**로 읽은 완성 메시지 표와 **자료로 메시지 만들기**에서 사용한 일정·배정표에는 실제 명단과 업무 내용이 들어갈 수 있습니다. 원본과 저장된 자료 모두 비공개로 취급하세요.

웹 서버는 `127.0.0.1`에서만 실행됩니다. 접속 URL과 세션 파일의 인증값은 공유하면 안 됩니다. 클라우드 업로드나 사용 통계 전송 기능은 포함하지 않습니다.

설치는 PyPI에서 지정 의존성을 받습니다. Google 연결을 선택하면 Google 인증·Sheets API를 사용합니다. 메시지는 로그인한 쿨메신저를 통해 기관의 메시징 서비스로 등록합니다.

## 내보내기와 캡처

| 항목 | 취급 |
| --- | --- |
| 공개본의 빈 기본·프리셋 양식 | 개인 자료가 입력되지 않았을 때 공유 가능 |
| 작성한 Excel·CSV, 업무 기록 CSV | 실제 명단·본문·파일 경로가 들어갈 수 있어 비공개 |
| 진단 정보 내보내기 | 버전·상태 통계 등 허용 항목 위주. 공유 전 직접 확인 |
| 연결 양식 내보내기 | 계정·본문·설치 경로·인증값을 제외하도록 구성. 공유 전 확인 |
| 캡처·콘솔·원시 오류 | 이름·본문·주소·인증값이 보일 수 있어 그대로 공개 금지 |
| Google OAuth JSON·토큰·session.json | 비공개 |

지난 메시지 정리는 보관함으로 옮기는 기능입니다. 내용과 등록 이력이 남으므로 완전 삭제가 아닙니다. 원본 파일·내보낸 파일·백업도 별도로 남을 수 있습니다.

**등록 요청 완료** 뒤 **확인 기록 남기기**는 선택입니다. 사용자가 확인한 사실을 로컬에 남기며 메시지를 다시 보내거나 수신함을 조회하지 않습니다. 확인 기록을 남기지 않아도 등록 시도 이력과 중복 방지는 유지됩니다.

## 공개 배포

개발 작업 폴더 전체를 GitHub 저장소로 만들지 마세요. 허용한 파일만 복사하고 검사한 별도 공개 폴더를 사용합니다. 운영 데이터·인계 기록·캡처·개인 양식·테스트 출력은 제외합니다.

검사는 파일 내용과 XLSX 내부 XML·외부 참조도 확인합니다. 별도 비공개 마커 목록으로 실제 이름·주소를 추가 점검할 수 있습니다. 자동 검사가 모든 개인정보를 구분한다는 보장은 없으므로 공개 ZIP의 포함 파일과 문서를 마지막으로 확인하세요. [공개 절차](PUBLISHING.md)를 따르세요.

실제 개인정보나 인증 파일을 공개 이슈에 올리지 마세요. 가상 자료로 재현 방법을 작성하고, 인증값이 노출됐다면 제공자에서 폐기·재발급하세요.
