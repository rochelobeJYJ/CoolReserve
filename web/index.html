동명이인은 조직과 전체 표시명을 확인하세요. 자료의 이름을 실제 계정과 연결한 뒤 예약합니다.

다른 버전 · 수동 화면 연결

수동 작성창 연결

자동 연결을 지원하지 않는 버전에서만 사용합니다. 조직도에서 본인 항목을 선택하고 본인에게 보내는 빈 작성창을 한 개 여세요. 참조·첨부가 없는지 확인하세요.

수동 연결 저장 → 연결용 작성창 닫기 → 메시지의 ‘1건 자동 입력’ 실행 → 입력 내용 확인 → 같은 작성창에서 ‘예약 등록’. 여러 수신자는 공동 수신 초안 한 건으로 확인해야 합니다.

‘지정’을 누르고 4초 안에 해당 쿨메신저 요소 위로 마우스를 옮기세요.

기본은 사용자 확인 방식입니다. 결과 목록 연결 없이 여러 건을 순서대로 등록하며, 접수 결과는 사용자가 확인합니다. 자동 대조 방식에서만 아래 연결을 사용합니다.
