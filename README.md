# 쿨 예약실 (CoolReserve)

쿨메신저 Gentoo에 여러 예약 메시지를 한 번에 등록하는 Windows 도구입니다. 메시지마다 수신자·본문·예약시각을 다르게 정하고 한 메시지를 여러 사람에게 보낼 수 있습니다. **제목은 선택 사항**입니다.

쿨메신저의 공식 제품이나 공식 API가 아닙니다. 로그인한 사용자의 작성창을 자동으로 조작하므로 등록 중에는 마우스·키보드를 잠시 비워두어야 합니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/rochelobeJYJ/CoolReserve/releases/latest)**에서 첨부된 배포 ZIP을 받으세요. 실행파일 하나로 된 제품이 아니라, 아래 설치 과정을 거쳐 사용하는 소스 배포본입니다.

대안으로 [저장소](https://github.com/rochelobeJYJ/CoolReserve)의 **Code → Download ZIP**을 이용할 수 있습니다. 이 방법은 최신 개발 소스를 받으므로 처음에는 Release의 배포 ZIP을 권장합니다.

## 처음 시작하기

준비할 것은 **Windows PC**, 기관 계정으로 로그인할 수 있는 **쿨메신저 Gentoo**, **설치할 때 사용할 인터넷 연결**입니다. Excel이나 Google 계정은 필수가 아닙니다. 처음 설치에는 **Python 3.14 64비트**를 권장합니다.

1. 위 다운로드에서 **ZIP 파일을 받습니다**.
2. ZIP을 **쓰기 가능한 폴더에 모두 풉니다**. ZIP 안에서 직접 실행하지 마세요. 파일들을 같은 폴더 구조로 유지합니다.
3. [Python 공식 Windows 배포](https://www.python.org/downloads/windows/)에서 **Python 3.14의 64비트 Windows 설치 프로그램**으로 설치합니다. 설치 화면에 `Add python.exe to PATH`가 있으면 선택하세요.
4. 압축을 푼 폴더에서 **INSTALL.cmd**를 두 번 누르고 설치 완료 안내를 기다립니다. 필요한 패키지는 이 폴더에 설치되며 관리자 권한은 필요하지 않습니다.
5. **쿨메신저에 로그인하고 조직도 창을 엽니다**. 온라인 사용자만 표시하지 않도록 전체 표시로 바꾸고, 작성 중인 내용은 보관한 뒤 다른 작성창을 닫습니다.
6. 같은 폴더의 **START.cmd**를 두 번 누릅니다. 브라우저에 쿨 예약실이 열립니다.
7. 앱의 **조직도 계정 불러오기**를 누르고 이름·소속·계정을 확인합니다. 연결은 이 PC에 저장되며 매번 반복하지 않습니다.
8. **새 메시지**에서 본인을 선택하고 **10분 이상 뒤**로 한 건을 시험 예약합니다. 미리보기에서 수신자·본문·시간을 확인한 뒤 등록하고, **등록 요청 완료**까지 PC 입력을 잠시 멈춥니다. 본인 계정 연결 안내가 나오면 [본인 시험 순서](docs/FIRST_RUN.md#본인에게-한-건-시험하기)를 따르세요.

다음 사용부터는 **쿨메신저 로그인·조직도 확인 → START.cmd**로 시작하면 됩니다. 설치나 계정 불러오기를 매번 할 필요는 없습니다.

[자세한 첫 사용 안내](docs/FIRST_RUN.md) · [설치·연결 문제 해결](docs/FIRST_RUN.md#문제-해결) · [오류 제보](https://github.com/rochelobeJYJ/CoolReserve/issues)

## 여러 메시지를 한 번에

입력 방법을 선택한 뒤 미리보기의 **등록 가능 N건 · 수정 필요 M건**을 확인합니다. 수정할 항목을 해결하고 한 번 등록하면 각 메시지를 차례로 입력·대조·등록합니다. 여러 메시지에 같은 예약시각을 지정할 수 있습니다.

| 입력 방법 | 사용할 때 |
| --- | --- |
| 새 메시지 | 한 건 작성, 여러 수신자 선택, 매주 반복 |
| 예약표 가져오기 | 수신자·내용·예약시각이 완성된 표를 Excel·CSV·붙여넣기로 가져오기 |
| 자료로 메시지 만들기 | 일정·배정표의 열과 안내 문구를 연결해 메시지 만들기 |

**엑셀 양식 받기**는 일반 예약용 빈 양식입니다. 필수 열은 `받는사람`, `예약날짜`, `예약시간`, `내용`이며 `제목`·`첨부파일`은 선택입니다. 제목 열 자체를 생략해도 됩니다. 열을 생략하거나 순서를 바꾼 표는 반드시 열 이름을 함께 복사하세요. 기존 `예약일시` 열도 읽습니다.

받는사람 한 셀에 이름을 쉼표나 줄바꿈으로 나누면 공동 수신 메시지가 됩니다. 이름 열만 복사했다면 **새 메시지 → 여러 명 선택·명단 붙여넣기**를 이용하세요. 동명이인은 실제 계정으로 구분하고 명단 전체가 확인돼야 적용됩니다.

제목을 비우면 프로그램은 작성창의 제목을 빈 값으로 입력합니다. 목록의 **제목 없음**은 화면 표시일 뿐 메시지 제목으로 넣지 않습니다. 본문·받는 사람·예약시각은 필수입니다.

## 일반 업무와 중식 지도

**자료로 메시지 만들기**는 일반 양식으로 시작합니다. 날짜·대상·내용 열을 연결하고 `{열 이름}`을 문구에 넣어 회의·당번·공지 등 다양한 자료에 사용할 수 있습니다. 설정은 저장해 다시 선택합니다.

**중식 지도**는 별도로 고르는 선택 프리셋입니다. 선택하면 전용 빈 엑셀 양식을 받을 수 있습니다. 확정 배정표의 1·2차 담당자, 제외일, 1차만 진행하는 날을 읽어 전체 일정을 안내합니다. 받는 방식·문구·지도 시간·발송시각을 바꿀 수 있으며 배정 자체를 계산하지는 않습니다.

Google 시트 직접 연결은 선택 기능입니다. 본인이 준비한 데스크톱 OAuth 클라이언트로 [Google 연결 안내](docs/google-connection.html)에 따라 승인합니다. Google 연결 없이도 Excel·CSV·붙여넣기를 사용할 수 있습니다. 원본 시트는 수정하지 않습니다.

## 등록 전 준비

- 쿨메신저 로그인 후 조직도를 열어두세요. 계정이 빠졌다면 전체 표시로 바꾸고 다시 불러오세요.
- 작성 중인 내용은 보관하고 다른 작성창을 닫으세요. 필요한 창은 프로그램이 엽니다. 입력 시험을 마친 단일 메시지는 화면 안내에 따라 해당 창을 남깁니다.
- 완료될 때까지 마우스·키보드 입력, 창 이동·크기 변경, 잠금·절전, 모니터·배율 변경을 피하세요. 고정 해상도나 위치를 요구하지 않으며 다중 모니터를 지원합니다.

완료·중단 시 PC 사용 가능 안내가 표시됩니다. **F8** 또는 **중지**는 현재 Windows 호출 이후 반영될 수 있습니다. 이미 접수된 예약은 앱 중지·종료로 취소되지 않습니다. 취소는 쿨메신저에서 하세요.

## 처리 결과

| 표시 | 의미 |
| --- | --- |
| 초안 | 아직 등록하지 않음 |
| 등록 요청 완료 | 정상 처리. 보내기와 작성창 종료를 마쳤고 다음 건을 처리함. 자동 재등록 잠금 |
| 확인 완료 | 사용자가 선택적으로 확인 기록을 남김. 자동 재등록 잠금 유지 |
| 중단 | 보내기 전 오류로 멈춤. 원인을 수정한 뒤 미등록 건을 다시 실행할 수 있음 |
| 등록 여부 불명 | 보내기 도중 오류가 발생함. 재등록이 잠기므로 쿨메신저에서 해당 건을 확인해야 함 |

기본 모드는 도착 여부·수신함을 조회하지 않으며 건마다 확인해야 다음 메시지를 처리하는 구조도 아닙니다. 보내기 전 특정 창 오류만 최대 한 번 준비를 재개하고 원문·계정·예약시각·첨부·이력을 다시 대조합니다. 보내기 이후에는 자동 재전송하지 않습니다.

**확인 기록 남기기**는 선택 사항입니다. 정상 결과인 **등록 요청 완료**를 그대로 두어도 됩니다. 표시 상태와 별개로 등록 시도 이력이 남은 메시지는 자동으로 재등록하지 않습니다.

**지난 메시지 정리**는 오늘 이전의 정리 가능한 항목을 보관함으로 옮깁니다. **보관함**에서 꺼내도 등록 기록과 중복 방지는 유지됩니다.

## 저장과 개인정보

자료·연결·등록 이력은 `%LOCALAPPDATA%\CoolReserve`에 저장됩니다. 웹 화면은 이 PC의 `127.0.0.1`에서만 열립니다. 브라우저를 닫아도 서버는 유지되며 앱 메뉴의 **프로그램 종료**로 종료합니다.

실제 명단·본문·Google 인증 파일·업무 CSV·화면 캡처는 공개하지 마세요. 버그 제보에는 **진단 정보**를 내보내고 내용을 확인하세요. 개발 작업 폴더 전체를 GitHub에 올리지 말고 [공개 절차](docs/PUBLISHING.md)의 별도 공개본을 사용합니다. [개인정보 안내](docs/PRIVACY.md)에서 저장·내보내기 범위를 확인할 수 있습니다.

## 지원 범위와 검사

Windows의 Gentoo **5.75.80.2**에서 일반·복수 수신자와 다건 예약 등록을 확인했습니다. 다른 버전·기관 설정·첨부파일 접수는 해당 환경에서 확인해야 합니다. 읽을 수 없는 화면이나 계정은 추측해 보내지 않고 멈춥니다. 제목 없는 입력·대조는 자동 검사로 검증했으며, 이 변경 후 쿨메신저에서 제목 없이 보내기를 완료하는 실사용 시험은 하지 않았습니다.

새 폴더의 설치·재설치는 **Python 3.14 64비트**에서 확인했습니다. Python 3.13 64비트도 지원 조건에 포함되지만 별도의 새 설치 시험은 하지 않았습니다.

한국시간 기준 최소 10분 후부터 3개월 이내를 지원합니다. Windows 시간대 UTC+09:00에서 사용하며 기본 목록은 최대 500건입니다. 기관 설정의 제한도 적용될 수 있습니다.

```powershell
.venv\Scripts\python.exe server.py --offline --open --data-dir .offline-data
```

```powershell
node -e "for (const f of require('fs').readdirSync('tests').filter(x=>x.endsWith('.cjs'))) require('./tests/'+f)"
```
